Police des écrans : Inter (licence libre SIL OFL).

- Sur les Raspberry Pi, install-ecran.sh l'installe automatiquement (paquet fonts-inter).
- Ailleurs, vous pouvez déposer ici le fichier InterVariable.woff2
  (téléchargeable sur https://rsms.me/inter/) pour l'embarquer dans l'application.

Sans Inter, l'affichage utilise Segoe UI, Roboto ou Arial selon le système.
