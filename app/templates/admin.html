    Installer un nouvel écran (Raspberry Pi)
    
      Sur le nouveau Raspberry Pi (Raspberry Pi OS Desktop, connecté au même réseau), ouvrez un terminal et collez cette commande en remplaçant NOM par le nom de l'écran (ex. : hall, cafeteria) :
      
    {% set server_host = request.host %}
    
      
      curl -fsSL http://{{ server_host }}/install-ecran.sh | bash -s -- --server {{ server_host }} --screen NOM
      
    
      
    {% if request.host.split(':')[0] in ('localhost', '127.0.0.1') %}
    
      ⚠ Vous consultez l'admin via localhost : remplacez-le par l'adresse IP du serveur dans la commande.
      
    {% endif %}
    
      Puis redémarrez le Pi : l'écran apparaît automatiquement dans la liste ci-dessus, où vous choisissez son thème.
      
  
      
  
      
    Installer un écran sur une box Android / Android TV
    
      Sur la box, téléchargez et installez l'application Axians Affichage :
      comaxians-ecran.apk
      (par exemple avec l'application Downloader). Au premier lancement, saisissez :
      
    
      • Adresse du serveur : {{ request.host.split(':')[0] }}  • Nom de cet écran : au choix (ex. : hall)
      
    
      L'écran apparaît ensuite dans la liste ci-dessus. Sur la box, la touche Retour de la télécommande rouvre les réglages.
      
  
      
  
      Adresse affichée par chaque écran : {{ url_for('display', _external=True) }}?screen=nom. Sans ?screen=, l'écran utilise le thème par défaut.
