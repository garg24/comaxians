Installer un nouvel écran (Raspberry Pi)

Sur le nouveau Raspberry Pi (Raspberry Pi OS Desktop, connecté au même réseau), ouvrez un terminal et collez cette commande en remplaçant NOM par le nom de l'écran (ex. : hall, cafeteria) :

{% set server_host = request.host %}
curl -fsSL http://{{ server_host }}/install-ecran.sh | bash -s -- --server {{ server_host }} --screen NOM
{% if request.host.split(':')[0] in ('localhost', '127.0.0.1') %}

⚠ Vous consultez l'admin via localhost : remplacez-le par l'adresse IP du serveur dans la commande.

{% endif %}
